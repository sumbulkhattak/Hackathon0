# Finance Memory

Store financial summaries, supplier info, and cost tracking here.

## Structure

- `daily/` — Daily revenue snapshots
- `suppliers.md` — Supplier contacts and pricing
- `refunds.md` — Refund tracking log
- `costs.md` — Operational cost notes

## Supplier Template

```markdown
# Supplier: {Name}

- **Contact:** {email / phone}
- **Products:** {categories supplied}
- **Lead Time:** {days}
- **MOQ:** {minimum order quantity}
- **Payment Terms:** {net 30 / advance / etc.}
- **Rating:** {1-5 stars}
- **Notes:** {any special conditions}
```

## Rules
- Update supplier pricing quarterly
- Track all refunds with order ID reference
- Flag any cost increases > 10%
