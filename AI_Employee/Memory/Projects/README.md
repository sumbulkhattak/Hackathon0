# Projects Memory

Store active campaigns, product launches, and improvement initiatives here.

## Structure

One file per project: `{project_slug}.md`

### Template

```markdown
# Project: {Name}

## Status: {PLANNING / ACTIVE / COMPLETED / ON HOLD}

## Overview
{1-2 sentence description}

## Timeline
- **Start:** {date}
- **Target Completion:** {date}
- **Actual Completion:** {date or "In Progress"}

## Tasks
- [ ] {task 1}
- [ ] {task 2}
- [x] {completed task}

## Notes
{any relevant context, decisions, blockers}
```
