# Pending Approval

Tasks in this directory have been processed by the AI and are awaiting human review.

## Review Process
1. Open the task file
2. Review the AI's work (drafted reply, restock plan, etc.)
3. **Approve:** Move file to `Approved/`
4. **Reject:** Move file to `Rejected/` with a note explaining why

## Review SLA
- URGENT items: Review within 2 hours
- Standard items: Review within 48 hours
- Items older than 48 hours trigger a reminder

## What to Check
- [ ] Response matches brand tone (see Company Handbook)
- [ ] Facts and data are accurate
- [ ] No sensitive information exposed
- [ ] Action items are appropriate
- [ ] Customer name and details are correct
